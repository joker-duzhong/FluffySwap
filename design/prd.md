第一部分：UI 设计风格指南（直接发给设计师）
既然我们的成本高、定价也偏中高端，且目标用户包含设计师/自媒体等专业人群，UI 绝不能做成花哨的“秀秀”风格，而应该走**“高级生产力工具”**路线。

主视觉风格 (Art Direction)：极致极简 (Minimalist) + 沉浸式暗黑/深色模式 (Dark/Dim Theme)。
    * 理由：深色背景最能凸显 AI 生成的高饱和度、高质量图片的质感（参考 Midjourney 官网和高端修图软件）。
色彩规范 (Color Palette)：
    * 背景色：深灰/纯黑（如 #121212 或 #0A0A0A）。
    * 强调色 (Accent Color)：建议用一种带有“AI 魔法感”的渐变色，例如 电光蓝 渐变 荧光紫，但极其克制地使用，只用在“开始生成”按钮或“会员/充值”的高亮标识上。其他按钮全用纯白或灰色。
组件质感 (Material & Texture)：
    * 大量使用 毛玻璃/背景模糊 (Glassmorphism) 效果。特别是底部导航栏、弹出的创作面板，使用毛玻璃能增加空间层次感，显得非常高级（类似 iOS 系统原生质感）。
    * 大圆角（如 radius-16 或 24），让冰冷的工具多一分亲和力。
字体排版 (Typography)：
    * 无衬线体（San Francisco / PingFang），标题粗体加大（Bold），次要信息极度弱化（低透明度的灰色）。
核心心法：UI 必须“退居幕后”，让用户生成的 AI 漂亮图片成为页面上唯一的视觉中心和色彩来源。
第二部分：小程序功能结构清单 (PRD 总览)
整体架构：采用底部 3 个 Tab 结构（发现、➕创作、我的）。

1. 【Tab 1：发现页 / 画廊】—— 核心目标：种草与降低门槛
UI 特殊要求：不要顶部的复杂导航，直接沉浸式大图展示。瀑布流布局。
功能点：
    * 顶部金刚区/分类（可选）：横向滑动的小标签，如“全部 / 插画 / 海报 / UI组件 / 摄影”。
    * 精选瀑布流图库：展示官方提供的高质量样图。
    * 图片详情弹窗/全屏页：
        * 查看原图。
        * 查看完整提示词 (Prompt)：展示这张图是怎么念咒的。
        * 【核心功能】“做一张同款”按钮：点击直接带入该图的提示词和参数，跳转到创作页。（极其重要，小白最爱）。
2. 【Tab 2：创作台】—— 核心目标：丝滑输入与消耗算力
UI 特殊要求：点击底部中央的 ➕ 号，从屏幕底部弹出一个占屏幕 70% 高度的毛玻璃抽屉 (Bottom Sheet)，不要离开当前页面，保持用户的连贯感。
功能点：
    * 文本输入框：支持多行输入。支持清空。
    * 语音输入按钮：点击按住说话，松开转文字。
    * 【核心功能】魔法棒 (AI 润色)：输入简单的词（如“一杯咖啡”），点击魔法棒，自动扩写为高质量的长提示词。
    * 参数配置区：
        * 尺寸比例：四个方形图标单选（1:1, 3:4, 4:3, 16:9）。
        * 模型选择 (折叠/下拉)：默认选中「旗舰高质模型」，下拉可切换至「基础模型」。
    * 生成按钮：按钮上必须明确写清消耗（例如：“🪄 开始创作 (耗 10 算力)”），按钮做亮色处理。
3. 【过渡页：生成等待态】—— 核心目标：安抚情绪
UI 特殊要求：因为贵模型出图可能需要 10-30 秒，绝对不能只放一个转圈圈，用户会焦躁退出。
功能点：
    * 流光骨架屏/呼吸灯动效：占满画幅区域，暗示正在渲染。
    * 动态提示语：随机轮播“正在构建画面结构...”、“正在补充光影细节...”、“AI 小贴士：更具体的形容词出图效果更好哦”。
4. 【结果展示页】—— 核心目标：惊艳展示与后续动作
UI 特殊要求：图片居中放大，背景可以是这张图的高斯模糊，营造大片感。
功能点：
    * 高清预览：支持双指放大看细节。
    * 保存到相册：
        * 逻辑判断：非会员/免费体验者加水印；会员/付费者无水印。
    * 重新生成按钮：一键再次消耗算力，重抽一张。
    * 【营销功能】生成分享海报：自动将生成的图 + 一段文艺文案 + 小程序二维码拼成一张精美的海报，供用户发朋友圈（免费裂变利器）。
5. 【Tab 3：工作台 / 我的】—— 核心目标：资产管理与复购
UI 特殊要求：类似 Dashboard（控制面板）的感觉，数据清晰，排版规整。
功能点：
    * 用户信息卡片：头像、昵称、会员标识。
    * 资产中心：
        * 大字显示：“当前剩余：XXX 算力（或次数）”。
        * 旁边放一个显眼的 【充值/升级】 按钮。
    * 历史作品库 (我的画廊)：
        * 以网格（Grid）形式倒序排列自己生成过的所有图片。
        * 支持多选删除、点击进入详情页重新查看提示词。
    * 系统功能列表：
        * 算力明细记录（账单：什么时候扣了多少，充了多少）。
        * 邀请好友（裂变：邀请得算力）。
        * 联系客服 / 问题反馈。
        * 关于我们。
